# All-users training — 45 minutes

**Status: NOT DELIVERED.** Outline for TRAIN-01. Use the sandbox project only.

## Learning outcomes

By the end, a user can sign in, navigate to their projects, create and update a
work item, collaborate with comments and mentions, manage notifications, search
and attach evidence, and open the mobile view.

## Agenda

| Minutes | Topic                           | Demonstration                                              | Practice                   |
| ------: | ------------------------------- | ---------------------------------------------------------- | -------------------------- |
|     0-5 | Sign-in and workspace home      | Sign in, identify workspace and projects                   | Each user signs in         |
|    5-12 | Project navigation and layouts  | List, board, backlog, cycle views                          | Open all layouts           |
|   12-22 | Work-item basics                | Create Bug/Task/Story; set type, state, priority, assignee | Create one practice item   |
|   22-30 | Comments, mentions and evidence | Comment, mention a colleague, attach a file                | Repeat in sandbox          |
|   30-36 | Notifications and email         | In-app bell, email, unsubscribe link                       | Identify own notifications |
|   36-41 | Search and filters              | Search by title, filter by assignee/type                   | Find own practice item     |
|   41-45 | Mobile and where to get help    | Open app on a phone; show `who-to-ask.md`                  | Questions                  |

## Notes for the trainer

- Do not use production data or production accounts.
- Show the blocked-transition message rather than bypassing it.
- Point trainees to the quick reference and the single support intake channel.
- Record attendance and the session; store both with the evidence register.
