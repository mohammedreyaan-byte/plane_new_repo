# Project-admin training — 60 minutes

**Status: NOT DELIVERED.** Outline for TRAIN-04. Use the sandbox project only.

## Learning outcomes

Project admins can manage members and roles, states, types, workflows, labels,
cycles, modules, views, integrations, service tokens, webhooks and reports.

## Agenda

| Minutes | Topic                             | Demonstration                                | Practice                |
| ------: | --------------------------------- | -------------------------------------------- | ----------------------- |
|    0-10 | Members and roles                 | Invite, change role, remove member           | Change one sandbox role |
|   10-22 | States, types and workflows       | Add a state, edit a workflow guard           | Inspect current config  |
|   22-30 | Labels, cycles and modules        | Create and assign each                       | Create one of each      |
|   30-38 | Views and saved filters           | Create and share a view                      | Share one view          |
|   38-48 | Integrations, tokens and webhooks | Show configuration surfaces only; no secrets | Identify owners         |
|   48-55 | Reports and audit                 | Run a report, inspect activity               | Verify one count        |
|   55-60 | Change control and support        | Hypercare decision log; `who-to-ask.md`      | Questions               |

## Guardrails

- Never display or copy tokens/webhook secrets during training.
- Configuration changes in hypercare require a decision-log entry.
