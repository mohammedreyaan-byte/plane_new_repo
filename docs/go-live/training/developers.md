# Developer training — 60 minutes

**Status: NOT DELIVERED.** Outline for TRAIN-02. Use the sandbox project only.

## Learning outcomes

Developers can plan and execute work from backlog and board, move bugs through
Code Review and In Testing, link pull requests, set estimates, create sub-items,
use bulk actions and apply keyboard shortcuts.

## Agenda

| Minutes | Topic                              | Demonstration                                             | Practice                  |
| ------: | ---------------------------------- | --------------------------------------------------------- | ------------------------- |
|     0-8 | Backlog ranking and cycle planning | Rank items, move into a cycle                             | Rank three practice items |
|    8-20 | Board workflow for bugs            | New to Code Review to In Testing; explain blocked columns | Move one bug              |
|   20-30 | Linking pull requests              | Reference a work-item ID in a PR title/body               | Link one practice PR      |
|   30-38 | Estimates and sub-items            | Set estimate, add child items                             | Add one child             |
|   38-48 | Bulk actions and filters           | Bulk assign/state change, saved filters                   | Apply to practice items   |
|   48-56 | Keyboard shortcuts and search      | Common shortcuts, quick search                            | Try each shortcut         |
|   56-60 | Questions and support channel      | `who-to-ask.md`                                           | Questions                 |

## Guardrails

- The developer cannot close a bug at `Tested`; QA owns that transition. Show
  the blocked message and explain why.
- Never paste credentials, tokens or PR URLs containing secrets into chat.
