# Quick reference — All users

**Draft for a two-page PDF. Publisher/date: not recorded.**

## Everyday actions

| Task           | Where                             | Key points                                                               |
| -------------- | --------------------------------- | ------------------------------------------------------------------------ |
| Sign in        | Workspace home                    | Use your invited account; contact support if access is missing           |
| Find a project | Workspace home / project switcher | You only see projects you belong to                                      |
| Create work    | Project -> New work item          | Pick Bug, Task, Story or Epic                                            |
| Classify       | Work-item detail                  | Type, state, priority, assignee, estimate, labels, cycle, module, parent |
| Discuss        | Work-item detail                  | Comment, mention a colleague, attach evidence                            |
| Notify         | Bell icon                         | In-app notifications; email follows your settings                        |
| Find           | Search / filters                  | Search titles; filter by assignee, type, priority                        |
| Mobile         | Browser on phone                  | Same account and permissions                                             |

## Rules

- Do not use production data for practice; use the training sandbox.
- A blocked transition is intentional; ask the named owner if unsure.
- Report issues through the single intake channel, not side messages.
- Never paste passwords or tokens into comments or chat.
