--------------------------------------------------------------------------------

    of a label.

Build a small reporting layer, not a BI builder. Reports must be reproducible by
URL, shareable, and exportable.

--------------------------------------------------------------------------------
REPORT DEFINITIONS
--------------------------------------------------------------------------------
Bug identification:
  - Use type.key == "bug" (type_id per project). For legacy projects with types
    disabled, fall back to the label `type: bug` and show a deprecation note.

Open:
  state.group in (backlog, unstarted, started)
  archived_at is null, deleted_at is null, is_draft=false

Resolved:
  state.group == completed
Cancelled:
  state.group == cancelled (reported separately, never counted as resolved)

Reports:
  1. bugs_by_state        open bugs grouped by state
  2. bugs_by_priority     open bugs grouped by priority
  3. created_vs_resolved  created vs completed per week/month
  4. cycle_burndown       remaining points/items per day (reuse cycle data)
  5. cycle_scope          added/removed items during a cycle
  6. module_progress      completed/total items and points per module

Time rules:
  - Creation uses created_at; resolution uses completed_at.
  - Convert to the project time zone; return the timezone in meta.
  - Reopened items clear completed_at and count as open again.

--------------------------------------------------------------------------------
DATA MODEL
--------------------------------------------------------------------------------
Project additions (schema migration):
  reports_enabled = BooleanField(default=True)
  reports_nav_visible = BooleanField(default=True)   # lets an admin hide the
                                                      # nav item without data loss

ReportDefinition(ProjectBaseModel):
  name CharField(120)
  report_type CharField(50)  choices above
  filters JSONField          validated per type; include a schema_version
  group_by CharField(50) blank
  chart_type CharField(20)   bar|line|table|donut
  is_shared Boolean default false
  created_by FK User
  deleted_at inherited
  unique active (project, name)

Do not store results. Cache computed responses for 60 seconds keyed by
(project, report_type, filters hash, user scope). Invalidate on issue/state
change via the existing cache helpers.

--------------------------------------------------------------------------------
API
--------------------------------------------------------------------------------
  GET    .../projects/<pid>/reports/
  POST   .../projects/<pid>/reports/
  GET    .../projects/<pid>/reports/<rid>/
  PATCH  .../projects/<pid>/reports/<rid>/
  DELETE .../projects/<pid>/reports/<rid>/
  GET    .../projects/<pid>/reports/<rid>/data/
  GET    .../projects/<pid>/reports/<rid>/export/      CSV
  GET    .../projects/<pid>/reports/bugs-by-state/     built-in
  GET    .../projects/<pid>/reports/bugs-by-priority/  built-in
  GET    .../projects/<pid>/reports/created-vs-resolved/
  GET    .../projects/<pid>/reports/cycle-burndown/?cycle_id=
  GET    .../projects/<pid>/reports/module-progress/

Response shape:
  {
    "report": "bugs_by_state",
    "generated_at": "...",
    "filters": {"type_id": "...", "cycle_id": null},
    "total": 42,
    "rows": [{"state_id": "...", "state": "In Testing",
              "group": "started", "count": 12}],
    "meta": {"timezone": "Asia/Kolkata", "open_definition": "..."}
  }

Filters: cycle_id, date_from, date_to, assignee_id, priority, label_id, type_id,
module_id. Limit date ranges to 2 years.

CSV:
  - Same filters; header includes filter metadata as comment lines or a second
    sheet-equivalent row.
  - Columns match the on-screen table exactly.
  - Escape formulas (=, +, -, @) to prevent CSV injection.

Permissions:
  - report.view: all project roles including Viewer.
  - report.export: admin/member/developer/qa; Viewer can view but not export.
  - Edit/delete: owner or project admin.
  - Cross-project 404.
