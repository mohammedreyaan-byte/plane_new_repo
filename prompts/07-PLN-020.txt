Flow:
  1. POST connect returns {redirect_url, state}. State is a signed nonce stored
     in cache for 10 minutes, bound to workspace and user.
  2. Callback verifies state, exchanges the installation id, stores metadata,
     creates the bot actor and an APIToken for the integration (existing
     WorkspaceIntegration.api_token FK requires one).
  3. Repository list is fetched with an installation token and cached 5 minutes.
  4. Linking a repository to a project creates/updates GithubRepository and
     GithubRepositorySync. Validate the repository belongs to the installation.
  5. Disconnect revokes the installation if possible, deactivates syncs, keeps
     links readable.

Webhook:
  - Read raw body; verify X-Hub-Signature-256 with HMAC-SHA256 and the secret in
    constant time. Invalid/missing -> 401, log delivery id.
  - Reject bodies over 25 MB.
  - Insert GithubWebhookDelivery before enqueueing; duplicate delivery_id ->
    200 and no work.
  - Celery task process_github_webhook(delivery_id):
      ignore unsupported event/action
      resolve repository mapping; ignore unlinked repositories
      parse identifiers; upsert PR/commit links idempotently
      update delivery status; retry transient errors 3x with backoff
  - PR events: opened, reopened, synchronize, closed, merged.
  - Push events: parse commit messages; upsert commits.

Identifier parsing:
  - Pattern: \b<PROJECT_IDENTIFIER>-<SEQUENCE>\b, case-insensitive.
  - Sources: PR title, PR body, branch name, commit message.
  - Resolve project by repository mapping; find issue by project.identifier +
    sequence_id. If the identifier changed, parse the numeric part and resolve
    within the repository's project only.
  - One reference creates one link; multiple references create multiple links.
  - Ignore references to other projects; log at debug.
  - Never create an orphan link with a required issue FK: if the issue does not
    exist, skip and log.

Merge behaviour:
  - auto_transition_on_merge = false (default): no state change.
  - auto_transition_on_merge = true: call transition_issue to merge_state_id
    using a system actor with work_item.transition capability. Respect the
    workflow; never force an invalid transition. Record source=github.
  - PR closed without merge: update link state only.

PERMISSIONS AND SECURITY
--------------------------------------------------------------------------------
- Connect/disconnect: workspace admin (integration.manage).
- Repository mapping, auto-transition: project admin.
- Read links: anyone who can view the work item.
- Verify the installation belongs to the expected account; bind state to the
  workspace to prevent installation swapping.
- Encrypt cached installation tokens; they expire after one hour.
- Never return tokens, private keys or webhook secrets in any response.
- Rate-limit the webhook endpoint and the connect/test endpoints.
- Log admin actions: connect, disconnect, link, unlink, auto-transition change.
