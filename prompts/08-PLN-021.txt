--------------------------------------------------------------------------------
EVENT CATALOGUE
--------------------------------------------------------------------------------
  work_item.created
  work_item.state_changed
  work_item.assigned
  work_item.priority_changed
  work_item.commented
  work_item.completed
  cycle.started
  cycle.completed
  module.completed

Default selection for a new sync:
  work_item.created, work_item.state_changed, work_item.commented

Rules:
  - Only post events selected on the sync.
  - Do not post for actions performed by the Slack bot itself.
  - Do not post when the sync is inactive or the project flag is off.
  - Deduplicate within 10 seconds by (event_key, entity_id, actor_id).
  - Truncate titles/comments to a safe length; always link to the work item.
  - Never include secrets, private attachment URLs or full descriptions.

Message format (Block Kit):
  header: "<TYPE> <IDENTIFIER> <title>"
  fields: State, Priority, Assignee
  context: "Changed by <actor>"
  actions: button "View in Plane" -> work item URL
  fallback text for notifications: "<IDENTIFIER> <title> - <event>"

--------------------------------------------------------------------------------
DELIVERY
--------------------------------------------------------------------------------
Celery task send_slack_event(event_log_id):
  - load log, skip if already sent or sync inactive
  - decrypt token
  - chat.postMessage(channel, blocks, text)
  - 200 -> sent, store ts; 429 -> retry after Retry-After, max 3 attempts;
    channel_not_found / not_in_channel / token_revoked -> failed permanently,
    deactivate sync if auth fails, notify the project admin
  - store response code and a short error, never the token
  - exponential backoff for 5xx and network errors
  - do not retry 4xx other than 429

Trigger points:
  - Issue create/update/comment services, after commit, enqueue one task per
    active sync.
  - Cycle and module state changes.
  - Use a dispatcher (apps/api/plane/utils/integrations/slack.py) so event
    emission is not scattered.

Test message:
  POST .../test/ posts a sample message and returns {ok, response_code, error}.
  Rate limit 5 per project per minute.

Disconnect:
  - Deactivate syncs, try auth.revoke, keep the delivery log, do not delete rows.
