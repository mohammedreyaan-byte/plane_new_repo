DATA MODEL
--------------------------------------------------------------------------------
1. Module additions:
     epic = FK("db.Issue", null=True, blank=True, on_delete=SET_NULL,
               related_name="epic_modules")
     epic_linked_at = DateTime(null=True)
     epic_linked_by = FK(User, null=True, on_delete=SET_NULL)
     progress_mode = CharField(20, choices items|epic_children|manual,
                               default="items")
     manual_progress = PositiveSmallInteger(null=True)  # 0-100
     manual_progress_note = TextField(blank=True)

2. Constraints/validation:
   - The linked issue must be in the same project, type.is_epic=true, not
     archived/deleted.
   - One Epic to one active Module per project (partial unique index on
     (project, epic) where deleted_at is null). This is the final decision:
     do not build a many-to-many join table in this prompt.
   - A Module may contain the Epic itself and/or its child Stories/Tasks/Bugs.
   - Unlinking sets epic=NULL, keeps items and progress.

3. Progress rules:
   items (default):
     completed ModuleIssue / total ModuleIssue, excluding cancelled and archived.
     Show count and points when estimates exist.
   epic_children:
     collect the linked Epic's descendants (Story/Task/Bug, configurable depth,
     default 2), completed / total, excluding cancelled/archived.
     Exclude the Epic itself from the denominator to avoid double counting.
   manual:
     manual_progress with a required note; admin-only.
   - Compute on read; cache 60 seconds; invalidate on item/state/module changes.
   - Use one shared completion helper with cycle progress so definitions match.

--------------------------------------------------------------------------------
API
--------------------------------------------------------------------------------
  GET    /api/workspaces/<slug>/projects/<pid>/modules/
  POST   .../modules/                          optional epic_id
  GET    .../modules/<mid>/
  PATCH  .../modules/<mid>/                    name, dates, status, progress_mode
  DELETE .../modules/<mid>/
  POST   .../modules/<mid>/link-epic/          {"epic_id": "..."}
  DELETE .../modules/<mid>/link-epic/
  GET    .../modules/<mid>/progress/           breakdown by type/state
  POST   .../modules/<mid>/issues/             bulk add/remove
  POST   .../modules/from-epic/                {"epic_id": "...", "name": "..."}

Response additions:
  epic_id, epic {id, name, sequence_id, state_id, state_name, type_id},
  progress {completed, total, percentage, points_completed, points_total,
            mode, as_of},
  children_summary {bug: n, story: n, task: n}

Validation errors:
  400 epic_required            linked item is not an Epic
  400 epic_wrong_project
  409 epic_already_linked      another module has it
  400 epic_archived
  400 manual_progress_required

Permissions:
  - Create/link/unlink: project admin/member (module.manage).
  - Add/remove items: project member with work_item.edit.
  - Developer/QA can add items but not change the Epic link.
  - Viewer read-only.
